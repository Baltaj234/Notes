Series of three learning paths that familiarize you with Azure and its many services and features.

Focuses on Compute, Networking, and storage devices. Also, learning about cloud security best practices, governance and management options.

Helps you prepare for Exam AZ-900 Microsoft Azure Fundamentals.

# Exam General Structure
Describe cloud concepts = 25-30%
Describe Azure architecture and services = 35-40%
Describe Azure management and governance = 30-35%
