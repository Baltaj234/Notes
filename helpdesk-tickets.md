# Common Helpdesk Tickets

Below is a consilidated list of the most commonly reported IT helpdesk issues.

## 1. Password & Authentication Issues

- Password rests
- Locked accounts
- MFA failures
- Incorrect Keyboard layout or expired passwords

## 2. Printer and Peripheral Problems

- Printer not responding
- Print queue failures
- Faulty or unorganized peripherals

## 3. Connectivity and Network Issues

- Wi-Fi not connecting 
- VPN failures
- Network drive access issues

## 4. Software Installation and Update Errors

- Failed installs
- Missing updates
- Application crashes

## 5. Hardware and Performance Problems

- Slow computers
- Device malfunctions
- System crashes or blue screens

## 6. Email and Collaboration tool issues

- Email not sending/receiving
- Calendar sync problems
- Communication tool login or sync failures

## 7. Access to Shared Resources

- Lost access to shared drives
- Permission errors

## 8. Data Loss or recovery Requests

- Deleted files
- Missing documents
